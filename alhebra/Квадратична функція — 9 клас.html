Теорія · 1 з 4

Що таке квадратична функція

Функцію виду y = ax² + bx + c, де x — змінна, a, b, c — числа і a ≠ 0, називають квадратичною функцією.

Головна ознака: найвищий степінь змінної x дорівнює 2. Коефіцієнти b і c можуть дорівнювати нулю, а a — ніколи (інакше зникне x² і вийде лінійна функція).

Графік будь-якої квадратичної функції — парабола. Найпростіша парабола — графік y = x².

Перевір себе (без оцінки): для функції y = 4 − 2x² + x визнач коефіцієнти.
Теорія · 2 з 4

Функція y = ax²: як a змінює параболу

Рухай повзунок і стеж, що відбувається.

Запам'ятай

Вершина параболи y = ax² завжди в точці (0; 0), вісь симетрії — вісь Oy.

a > 0 — гілки вгору; a < 0 — гілки вниз.

Чим більше |a|, тим «вужча» парабола; чим ближче a до нуля, тим вона «ширша».

Значення функції в точках x і −x однакові, бо (−x)² = x². Тому таблицю значень можна рахувати лише для додатних x.

Теорія · 3 з 4

Парабола y = ax² + bx + c і її вершина

Графік — та сама парабола, лише зсунута. Щоб її побудувати, спочатку знаходимо вершину:

x₀ = −b / (2a),   y₀ = y(x₀)

Пряма x = x₀ — вісь симетрії параболи (червона пунктирна).

Синя точка — вершина, червоні — нулі функції, зелена — перетин з віссю Oy.

Теорія · 4 з 4 · Розібраний приклад

Будуємо графік y = x² − 4x − 5 крок за кроком

  1. Напрям гілок. a = 1 > 0, отже гілки напрямлені вгору.
  2. Вершина. x₀ = −(−4) / (2·1) = 2;   y₀ = 2² − 4·2 − 5 = −9. Вершина (2; −9).
  3. Вісь симетрії: пряма x = 2.
  4. Нулі функції: x² − 4x − 5 = 0, D = 16 + 20 = 36, x = −1 або x = 5. Точки (−1; 0) і (5; 0).
  5. Перетин з Oy: x = 0, y = −5, точка (0; −5). Симетрична їй відносно x = 2 — точка (4; −5).
  6. Проводимо плавну лінію через усі точки. Готово!
Властивості за графіком:

1) D(y) = (−∞; +∞);  2) E(y) = [−9; +∞);

3) нулі: x = −1 і x = 5;

4) y > 0 при x < −1 або x > 5;  y < 0 при −1 < x < 5;

5) спадає на (−∞; 2], зростає на [2; +∞);

6) найменше значення y = −9 (при x = 2).

Завдання 1 з 7

Які з функцій є квадратичними?

Познач усі правильні варіанти.

Квадратичні: y = 3x² − 2x + 1; y = 7 − x² (a = −1); y = 0,5x²; y = (x + 2)², бо (x + 2)² = x² + 4x + 4.

Не квадратичні: y = 5x − 4 (лінійна); y = 2/x² + 1 (x у знаменнику); y = x³ − x² (є x³).

Завдання 2 з 7

Чи є графік параболою? Куди напрямлені гілки?

Для кожної функції обери відповідь.

Дивимось на коефіцієнт при x²: якщо він додатний — гілки вгору, якщо від'ємний — вниз. Якщо x² немає (або є x³, 1/x) — це не парабола.

1) вгору (a = 2); 2) вниз (a = −1); 3) не парабола; 4) вгору (a = 0,1); 5) вниз (a = −½); 6) не парабола.

Завдання 4 з 7

Точки перетину графіка y = −2x² з прямою

Не будуючи графіків, знайди координати точок перетину. Порядок точок неважливий. Якщо перетину немає — постав позначку.

Прирівнюємо праві частини.

1) −2x² = −8 → x² = 4 → x = ±2; y = −8. Точки (−2; −8), (2; −8).

2) −2x² = 10 → x² = −5 — коренів немає, графіки не перетинаються.

3) −2x² = 4x → x(x + 2) = 0 → x = 0 або x = −2; y = 4x: (0; 0), (−2; −8).

Шпаргалка

Квадратична функція

y = ax² + bx + c, a ≠ 0

Найвищий степінь x — другий. Розкрий дужки, якщо вони є: (x + 2)² = x² + 4x + 4.

Куди дивляться гілки

a > 0 — вгору ∪   a < 0 — вниз ∩

a — число перед x², з його знаком.

Вершина і вісь

x₀ = −b / (2a)

y₀ — підстав x₀ у формулу функції.

Вісь симетрії: пряма x = x₀.

Для y = ax² вершина (0; 0).

Нулі (перетин з Ox)

Розв'яжи ax² + bx + c = 0:

D = b² − 4ac,  x = (−b ± √D) / (2a)

D > 0 — 2 точки, D = 0 — 1, D < 0 — жодної.

Перетин з Oy

Підстав x = 0: точка (0; c).

Алгоритм побудови

  1. Напрям гілок (знак a).
  2. Вершина (x₀; y₀).
  3. Вісь симетрії x = x₀.
  4. Нулі та точка (0; c).
  5. Ще 2–4 точки поруч із вершиною — вони парні, симетричні відносно осі.
  6. Плавна лінія через усі точки.

Властивості (a > 0)

D(y) = (−∞; +∞); E(y) = [y₀; +∞)

спадає на (−∞; x₀], зростає на [x₀; +∞)

найменше значення y₀. Якщо a < 0 — усе навпаки, y₀ найбільше.

Перетин двох графіків

Прирівняй праві частини, розв'яжи рівняння — отримаєш x. Потім знайди y з рівняння прямої.

Коренів немає → графіки не перетинаються.

Як вводити відповіді

Дроби — через кому або крапку: 0,45 або 0.45. Мінус — звичайний дефіс: −3 → -3.
